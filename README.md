# Simple Calculator (CLI)

## Project Description

The Simple Calculator is a command-line interface (CLI) Python project that performs basic arithmetic operations such as Addition, Subtraction, Multiplication, and Division. It takes user input, processes the selected operation, and displays the result in the terminal.

This project is designed for beginners to understand Python fundamentals like functions, conditional statements, user input handling, and exception handling.

---

## Features

- Addition of two numbers
- Subtraction of two numbers
- Multiplication of two numbers
- Division of two numbers
- Handles invalid input
- Prevents division by zero errors
- Simple menu-driven interface

---

## Technologies Used

- Python 3
- Command Line Interface (CLI)
